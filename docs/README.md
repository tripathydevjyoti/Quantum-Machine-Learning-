# Documentation

The documentation is split by task:

- [`data.md`](data.md) describes the study dataset, forecasting task, chronological splits, and preprocessing rules.
- [`reproducibility.md`](reproducibility.md) gives environment, execution, Slurm, and validation instructions.
- [`experiment-map.md`](experiment-map.md) maps each experiment family to its training script, scheduler entry point, analysis workflow, and curated output.

The top-level README provides the project overview. Historical LSTM-autoencoder and early hybrid-QNN material is documented separately under `legacy/`.
