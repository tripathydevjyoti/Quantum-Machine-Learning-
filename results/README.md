# Curated results

This directory contains compact, publication-facing outputs from the QNN time-series study.

## Contents

- `tables/ideal/forecasting/`: five-encoding ideal forecasting summaries, paired comparisons, dataset characterization, and the run manifest.
- `tables/ideal/validation/`: consistency checks and validation records for the ideal results.
- `tables/ideal/encoding_diagnostics/learnable_seasonal_cdf_rz/`: validation of the fifth encoding, `learnable_seasonal_cdf_rz`.
- `tables/ideal/geometry/`: aggregated temporal-fidelity, seasonal-prominence, reconstruction, and directional-QGT diagnostics.
- `figures/`: reserved for the final publication figure set.

The ideal study contains five encodings, six circuit depths, and five random seeds. Large checkpoints, raw prediction arrays, intermediate diagnostics, and duplicate report outputs are not included.

Noisy Aachen results will be added separately after the relevant simulation blocks are complete and validated.
