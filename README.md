# Quantum Machine Learning for Seasonal Time-Series Forecasting

This repository contains code and reproducibility assets for studying
data-reuploading quantum neural networks for seasonal time-series forecasting,
including depth-dependent performance, encoding geometry, spectral retention,
and resilience under finite-shot noisy simulation.

The publication-facing implementation, experiment configurations, analysis
code, curated results, and reproduction instructions are being organized on
the `paper-reproducibility-cleanup` branch.

Earlier LSTM-autoencoder, latent-space QNN, hybrid-QNN, and small-qubit
experiments are preserved under [`legacy/`](legacy/README.md).

Detailed installation, dataset preparation, experiment, and reproduction
instructions will be added in subsequent commits.
