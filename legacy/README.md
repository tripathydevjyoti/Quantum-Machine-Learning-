# Legacy experiments

This directory preserves experiments and implementations that predate the
current seasonal time-series QNN study.

The `pre_paper_repository` directory retains the earlier repository structure,
including the LSTM-autoencoder, latent-space QNN, hybrid-QNN demonstrations,
and early small-qubit experiments.

These files are retained for historical context and are not part of the
publication-facing reproduction workflow. Generated checkpoints, numerical
arrays, caches, virtual environments, and the raw dataset were removed during
repository cleanup.
